# Stay Direct — independent stay landing page demo

A responsive, three-language landing page concept for a small accommodation business in Türkiye. Switch between English, Turkish, and Arabic. A guest can choose dates and guest count, then prepare a WhatsApp inquiry for the property's own number.

**This is a portfolio demo.** “Aegean Hideaway,” its room, and its descriptions are examples. It does not check availability, make reservations, collect payments, or represent an operating property.

## View locally

Open `index.html` in a browser. No build step, paid API, or external asset is required.

## Adapt for a real business

Replace the sample name and details in the three `copy` translations, add real images and policies, and connect the property's own WhatsApp number. The demo currently asks the visitor to type that destination number so that it cannot accidentally send inquiries to an unapproved business.

## Technology

Static HTML, CSS, and JavaScript. No tracking or backend.
